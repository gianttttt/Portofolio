Tentang Saya

Saya adalah seorang mahasiswa D4 Teknologi Rekayasa Perangkat Lunak Universitas Pendidikan Ganesha yang sedang mendalami dunia pemrograman dan pengembangan web. Saat ini, saya berfokus mempelajari HTML, CSS, JavaScript, serta berbagai framework modern untuk membangun aplikasi yang responsif, interaktif, dan bermanfaat.

Selain web development, saya juga memiliki minat pada bidang Animasi 3D, manajemen database, dan keamanan sistem sebagai bagian dari perjalanan saya di dunia teknologi it.

Di luar dunia teknologi, saya memiliki hobi bermain musik. Saya senang mengeksplorasi chord gitar, membuat aransemen sederhana. Bermain musik membantu saya menyeimbangkan antara logika dan kreativitas.

Saya percaya bahwa teknologi memiliki peran penting dalam mempermudah kehidupan sehari-hari. Karena itu, saya berkomitmen untuk terus belajar, berinovasi, dan berkontribusi melalui karya serta project yang saya kembangkan.
